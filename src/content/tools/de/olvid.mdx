  <Fragment slot="what">
    Ein französischer Messenger, der <b>ohne persönliche Daten</b> auskommt: keine Telefonnummer,
    keine E-Mail, kein Adressbuch.
  </Fragment>
  <Fragment slot="why">
    Ende-zu-Ende-Verschlüsselung, veröffentlichter Quellcode der Apps (AGPL), von der französischen
    Cybersicherheitsbehörde ANSSI zertifiziert (CSPN). Die französische Regierung nutzt ihn für ihre
    Kommunikation.
  </Fragment>
  <Fragment slot="who">
    Alle, besonders wer einen europäischen Anbieter und europäische Server bevorzugt. Kontakte fügt
    man persönlich oder per Einladung hinzu.
  </Fragment>
  <ol slot="install">
    <li>
      Installiere Olvid über <b>olvid.io</b>, den App Store oder Google Play. Die Basisversion ist
      kostenlos.
    </li>
    <li>Wähle einen Anzeigenamen: Eine Registrierung ist nicht nötig.</li>
    <li>
      Füge einen Kontakt per QR-Code hinzu oder tausche eine Einladung und danach einen 4-stelligen
      Code aus.
    </li>
  </ol>
