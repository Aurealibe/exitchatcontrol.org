## Gestore di password

Una password robusta e unica per ogni servizio: la base di tutto ciò che segue. Basta con il quaderno, basta con la password riutilizzata.

<ToolCard tool="t-bitwarden">
  <Fragment slot="tags">
    <span class="tool-tag">🟢 Principiante</span>
    <span class="tool-tag">Il migliore per iniziare</span>
    <span class="tool-tag">🌍 · open source</span>
  </Fragment>
  <Fragment slot="what">
    Una cassaforte di password che ricorda, genera e compila le tue password al posto tuo, su tutti
    i tuoi dispositivi.
  </Fragment>
  <Fragment slot="why">
    Gratuito, verificato, multipiattaforma e cifrato end-to-end. Devi ricordare una sola password
    robusta. Puoi persino <b>ospitarlo tu stesso</b> (tramite Vaultwarden) per non dipendere da
    nessuno.
  </Fragment>
  <Fragment slot="who">
    Tutti. È la base di ogni sicurezza: una password robusta e unica per ogni servizio.
  </Fragment>
  <ol slot="install">
    <li>
      Crea un account su bitwarden.com e scegli una master password <b>lunga</b> (una frase). Non
      dimenticarla mai: non può essere recuperata.
    </li>
    <li>Installa l'estensione del browser e l'app mobile.</li>
    <li>
      Man mano che accedi, lascia che Bitwarden salvi e poi sostituisca le tue vecchie password con
      password generate.
    </li>
  </ol>
</ToolCard>

<ToolCard tool="t-keepassxc">
  <Fragment slot="tags">
    <span class="tool-tag">🔴 Avanzato</span>
    <span class="tool-tag">100% locale</span>
    <span class="tool-tag">🌍 · open source</span>
  </Fragment>
  <Fragment slot="what">
    Una cassaforte <b>locale</b>: un file cifrato che possiedi solo tu, senza cloud né account.
  </Fragment>
  <Fragment slot="why">
    Nulla lascia il tuo dispositivo, a meno che tu non scelga di sincronizzare il file da solo (ad
    esempio tramite Cryptomator). È la scelta del purista, senza alcun intermediario.
  </Fragment>
  <Fragment slot="who">
    I profili avanzati che vogliono il pieno controllo e zero dipendenze online.
  </Fragment>
  <ol slot="install">
    <li>
      Installa KeePassXC (desktop) e un'app mobile compatibile (KeePassDX su Android, Strongbox su
      iOS).
    </li>
    <li>Crea un file di database protetto da una master password.</li>
    <li>Per averlo su tutti i dispositivi, sincronizza quel file tramite un cloud cifrato.</li>
  </ol>
</ToolCard>
